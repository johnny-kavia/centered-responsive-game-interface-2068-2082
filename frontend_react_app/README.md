# Dark Tic Tac Toe (React)

Modern, minimal, dark-themed Tic Tac Toe with local two-player gameplay.

## Features
- Local two-player play (X vs O)
- Turn indicator
- Win detection + highlighted winning line
- Draw detection
- Restart round / next round button
- New game (resets scoreboard)
- Centered responsive layout + dark-mode styling

## Run
```bash
npm install
npm start
```

App runs on port 3000 by default.
